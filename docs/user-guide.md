# 使用说明

## 安装与升级

在 [0.3.0 Beta 2](https://github.com/evan-dev0608/MediaGlean/releases/tag/client-0.3.0-beta.2) 下载 `MediaGlean-*-win-x64-Setup.exe`。按当前用户安装；更新前退出应用。无需手动安装 Python、ParseHub 或媒体工具。

当前为尚未进行 Windows 产品代码签名的 Beta 版。0.3 使用 `%LOCALAPPDATA%/MediaDownloader/v6`，不迁移旧版数据。卸载不会删除已有下载文件。

从 Beta 2 起，默认安装目录是 `%LOCALAPPDATA%\Programs\MediaGlean`。如果上一版装在旧的默认目录 `%LOCALAPPDATA%\Programs\MediaDownloader`，先在 Windows 设置中卸载，再运行新版安装程序。应用数据位于独立目录，卸载后会保留。

## 解析与下载

在“新建下载”粘贴作品链接或完整分享文案，多作品可分行输入。点击“解析并预览”，确认封面、标题和类型后点击“开始下载”。所有任务统一在“下载管理”中查看。

保存位置在“设置”中配置，文件按平台和作品归档，图集按原始顺序编号。任务菜单可打开对应文件夹。

## 平台连接与工具

“设置 → 平台连接”按平台保存 Cookie 和代理。Cookie 在本机加密保存，重新选择平台可以看到保存状态与隐藏内容，必要时使用显示按钮查看。不要把凭据发到公开 Issue 或截图中。

微信视频号解析使用腾讯元宝的登录 Cookie，具体要求见界面提示；目前尚未完成带凭据视频号完整下载验证。

媒体工具默认自带；本地目录须同时包含可用的 x64 `ffmpeg.exe` 和 `ffprobe.exe`。应用检查配对能力与摘要，在线更新不会覆盖显式指定的外部目录，清理也不会删除它。Python 当前按完整环境包管理，不支持直接替换系统 Python。

## 更新

- 应用：从最新应用 Release 下载安装程序。
- ParseHub：检查官方 PyPI 原始 wheel，保留上游版本，安装前验证依赖兼容性。
- 执行环境：检查 Worker、Python 与依赖、媒体工具，仅下载有兼容更新的部分。

下载后先验证完整执行组合，再等待任务空闲切换；失败恢复上一组合。“没有兼容的更高版本”表示暂无可安装更新。组件包和签名清单无需手动解压到程序目录。

## 常见问题

### 为什么安装包仍有约 146 MiB？

完整离线包包含原生应用、Python、上游依赖和媒体工具。拆分减少后续更新流量，不移除首次运行环境。当前没有在线精简安装器。

### 为什么某个平台失败？

检查错误提示、网络和登录配置，再检查 ParseHub 与执行组件更新。目录接入不保证每一种作品均可下载。HLS 当前只支持有界、未加密的 MPEG-TS 分段；直播、加密流等暂不支持。

### UPDATE_NETWORK 是什么？

无法连接更新源，可稍后重试。更新源与媒体平台是不同连接；更新失败不等于当前解析组件不可用。不要手动覆盖目录绕过校验。

### 如何反馈？

到 [Issues](https://github.com/evan-dev0608/MediaGlean/issues) 提供应用及组件版本、Windows 版本、公开作品链接、步骤和错误码。删除凭据、个人路径和私密链接后再上传日志。
